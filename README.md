# Cart Product App 🛒

This is a simple **shopping cart web application** built using **React.js**. The project demonstrates core React concepts such as components, state management, and dynamic UI updates.

## 🚀 Live Demo

https://dwaikat-dalia.github.io/Cart-Product/

## 🛠️ Built With

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3

## 📌 Features

* Display products in a clean UI
* Add products to cart
* Remove items from cart
* Update cart state dynamically
* Responsive design for different screen sizes

## 🎯 Purpose

This project was built to practice React fundamentals and improve my skills in building interactive and dynamic web applications, especially working with state and component-based architecture.
